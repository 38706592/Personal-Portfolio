# 張紘偉作品集網站

這是一個展示張紘偉各種作品的網站，包括 Unreal Engine、AE影片、服裝設計、3D列印以及專題。

## 網站功能

- 響應式設計，適配各種螢幕尺寸
- 頁面切換動畫效果
- 圖片燈箱效果，點擊圖片可放大查看
- 影片嵌入播放
- 滾動動畫效果

## 使用方法

1. 直接在瀏覽器中打開 `index.html` 文件即可瀏覽網站
2. 點擊頂部導航欄可切換不同的作品分類
3. 點擊任何圖片可以放大查看
4. 在關於我頁面，滑鼠懸停在底部可以查看詳細信息

## 目錄結構

- `/css` - 包含網站樣式文件
  - `style.css` - 主要樣式文件
  - `lightbox.css` - 燈箱效果樣式
- `/js` - 包含網站腳本文件
  - `script.js` - 主要腳本文件
  - `lightbox.js` - 燈箱效果腳本

## 文件來源

網站使用了 `../素材/` 目錄中的圖片、影片和字體文件，包括：

- 字體文件：HorrorJoys-Rough.ttf、中国龙中粗黑.TTF、QUANTUM.OTF
- 圖片文件：來自各個作品分類的圖片
- 影片文件：各項目的展示影片

## 注意事項

- 本網站使用相對路徑引用素材，請確保保持目錄結構不變
- 如需修改素材路徑，請同時更新 HTML、CSS 和 JavaScript 文件中的相應引用
- 網站使用了現代 CSS 和 JavaScript 功能，建議使用最新版本的瀏覽器
